# Xero Reports — Edge extension (v1.2)

One click downloads all reports for the Xero client you have open.

## Install (each user)
1. Unzip. Go to edge://extensions -> Developer mode ON -> Load unpacked -> select this folder.
   (Updating? Remove the old version first, or press Reload on its card.)
2. Edge Settings -> Downloads -> turn OFF "Ask me what to do with each download".
3. Log in to Xero, open the client, click the extension -> Download All Reports.
4. While it runs, leave the automation tab VISIBLE. Work in another Edge WINDOW if needed.

Files: Downloads/Xero Reports/<Client>/<yyyy-mm-dd>/
